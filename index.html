Visible overlays and embedded provenance are different

This workspace only changes the visible preview and exported pixels.

Visible mark

The corner graphic you can see in an image or clip. Use the preview and controls to adjust how this visible area looks in your exported copy.

Embedded provenance

Some generated files can contain non-visible provenance information. This visual editor does not inspect or remove hidden metadata or digital watermarks.

Before you get started.

A few practical details about formats, previews, privacy, and exports.

01 How do I use the studio?
Choose Image studio or Video studio, add a compatible file, and inspect its preview. Adjust the controls until the result looks right, then create a separate copy. Results depend on the source and your settings.
02 Which image files can I open?
The image workspace accepts PNG, JPG, and WebP files. Your browser and device determine how large a file you can comfortably process.
03 Which video files can I open?
The video workspace accepts MP4, WebM, and MOV files, subject to browser codec support. Try a short clip first if you are unsure whether your device can handle it.
04 Does the preview guarantee the final result?
The preview shows the selected adjustment on the media currently loaded. Check the exported copy too: codecs, image content, and chosen settings can affect the final appearance.
05 Do I need to create an account?
No account is needed to use the editor. Processing larger files may be limited by available browser memory and device performance.
06 Does it change embedded provenance information?
No. The editor works with visible pixels and does not inspect or remove hidden metadata or digital provenance information.
07 Are my files uploaded?
Media is processed in your browser rather than uploaded to a processing server. The page loads resources such as fonts and icons from third parties; read the privacy policy for more information.
08 Can I switch off a mark in the generator?
This editor does not control any image or video generator settings. Check the settings and terms of the service that created your media.
09 Does the editor recover obscured image detail?
No editor can guarantee recovery of image detail that was covered in the source. This studio applies adjustable processing; inspect the preview and use the export only if it meets your needs.
10 Can I use the studio on a phone?
The layout adapts to smaller screens, though processing performance and supported video codecs vary by device and browser.
11 What happens to my original file?
The studio creates an output copy; your selected original file is not overwritten. Keep your own backup if the source is important.
12 Who made this studio?
The project is created by Amit Kumar. Visit the portfolio or GitHub profile for more.
